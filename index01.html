¿Qué es HTML en profundidad? Lenguaje de marcado ➜ declara la semántica de cada parte (qué es), no cómo se verá. Declarativo ➜ describe el resultado deseado; el navegador decide la representación. Independiente de plataforma ➜ cualquier SO con user agent lo interpreta. No posee lógica de control (bucles, condicionales). Para interacción se recurre a JavaScript.

Imagina que construir una página web es como hacer un edificio: 🧱 HTML son los ladrillos: Define la estructura básica (dónde van las paredes, puertas, ventanas) 🎨 CSS es la pintura y decoración: Decide colores, estilos y aspecto visual 💡 JavaScript es la electricidad: Agrega interactividad y funciones dinámicas Analogías Cotidianas

Como un periódico: HTML organiza las secciones (titulares, artículos, imágenes) No define el tamaño de letra o colores (eso es CSS)

Como el esqueleto humano: HTML es la estructura ósea (huesos) CSS sería la piel y apariencia JavaScript serían los músculos que permiten movimiento
